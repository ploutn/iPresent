# iPresent Pro

A modern church presentation and media management app built with React, Vite, and Electron.

## Features

- Song, Bible, Media, and Announcement management
- Live presentation and output preview
- Schedule and queue system
- Dark mode and modern UI
- Interactive elements (polls, timers, etc.)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [pnpm](https://pnpm.io/)

### Install dependencies

```sh
pnpm install
```

### Run the app (development)

```sh
pnpm dev
```

### Build for production

```sh
pnpm build
```

### Run Electron (desktop)

```sh
pnpm run electron
```

## Project Structure

- `src/` — Main source code
- `src/components/` — React components
- `src/types/` — TypeScript types
- `src/store/` and `src/stores/` — State management
- `src/utils/` — Utility functions
- `src/hooks/` — Custom React hooks
